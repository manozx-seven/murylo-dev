Regras do Firestore

Com o login real ativo, restrinja a escrita à sua conta. Cole estas regras no Firebase Console → Firestore → Regras (troque o e-mail pelo da sua conta):

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {

    // Bio: qualquer um lê; só a sua conta escreve
    match /bio/{doc} {
      allow read: if true;
      allow write: if request.auth != null
        && request.auth.token.email == 'murylo.neves@tjam.jus.br';
    }

    // Coleção antiga de senha não é mais usada
    match /admin/{doc} {
      allow read, write: if false;
    }
  }
}

Agora o banco só aceita gravações de quem estiver logado com a sua conta — o painel continua salvando normalmente.
