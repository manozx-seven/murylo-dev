Recomendação importante

Este painel valida a senha no navegador. Para segurança real, restrinja a escrita no banco com regras do Firestore. Regras sugeridas:

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    // Bio: leitura pública, escrita bloqueada via web
    match /bio/{doc} {
      allow read: if true;
      allow write: if false;
    }
    match /admin/{doc} {
      allow read, write: if false;
    }
  }
}

Com isso, edições passam a exigir o Firebase Console / Admin SDK. Para edição pelo painel com segurança total, migre para o Firebase Authentication.
